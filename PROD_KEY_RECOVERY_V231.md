# V231 — Kit de récupération hors ligne

Primitives pour quatre clés indépendantes : Fernet sauvegarde, MFA, documents, et Ed25519 signature. Format DSIG-KEY-RECOVERY-V1, scrypt N=131072 r=8 p=1 (environ 128 Mio), sel aléatoire 16 octets, AES-256-GCM nonce 12 octets, en-tête authentifié. Le secret de récupération doit être généré aléatoirement et conservé séparément (coffre de mots de passe ou support physique sécurisé) ; la longueur minimale seule ne garantit pas son entropie. Les empreintes de référence REC et candidate doivent provenir de sources indépendantes et couvrir toutes les clés existantes avant tout usage métier. Les empreintes attendues du nouveau kit doivent être sauvegardées indépendamment du kit, avec son SHA256. Le fichier local est créé sans remplacement, mode 0600, parent 0700. Les tests sont synthétiques avec coût KDF réduit uniquement dans les tests. Aucun provisionnement automatique, aucune écriture B2, aucune activation PROD. Le contrôle local ne prouve pas une récupération hors VPS. Ne pas supprimer les anciens secrets lors d'une rotation : les archives existantes restent liées à leurs clés. Étape suivante : qualification réelle avec coût complet, copie chiffrée externe et exercice de récupération sur poste indépendant, puis décision humaine de provisionnement métier.
