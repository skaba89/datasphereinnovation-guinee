# V232 — Qualification distante du cycle signé

Le module vérifie un cycle local complet et ses deux archives, contrôle la politique B2, envoie une copie dans prod/qualification/v232/<identifiant unique>/, télécharge et restaure les octets distants. Le nouvel adaptateur ne peut accéder aux noms métier. Le résultat est uniquement une qualification ; le journal signé local ne constitue pas une preuve d'ancrage distant. Le transfert B2 n'est pas atomique create-if-absent : un seul écrivain et un identifiant aléatoire indépendant sont requis. Le même identifiant est réutilisé pour une relance. Aucun timer ni appel réseau automatique. Les tests utilisent un stockage simulé ; la qualification B2 réelle nécessite une exécution dédiée sur VPS. Une archive distante déjà existante et différente est refusée, jamais remplacée. Ancrage externe, horloge réelle et politique de rétention restent à finaliser.
