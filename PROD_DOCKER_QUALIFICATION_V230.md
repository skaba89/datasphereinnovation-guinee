# V230 — Qualification Docker positive isolée

Le validateur métier conserve ses noms stricts. Une API distincte accepte uniquement dsig-qualification-<16 hex> et son volume dédié. Le script explicite utilise une image locale épinglée, sans réseau ni port, utilisateur 10001, ressources limitées, données synthétiques, extraction SQLite online backup et cycle local V228. Aucune clé métier, aucune écriture B2, aucun timer, aucune activation PROD. Les ressources créées sont supprimées par identifiant et nom uniques en finally ; une interruption brutale peut nécessiter un nettoyage manuel ciblé. La qualification ne prouve ni la provenance métier ni la capacité de production. Le script nécessite Docker local et une image DSIG préconstruite du commit qualifié ; il doit être exécuté sur un environnement autorisé. Les tests unitaires vérifient le namespace distinct.
