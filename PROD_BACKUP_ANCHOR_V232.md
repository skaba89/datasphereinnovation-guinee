# V232 — Ancrage externe de qualification

Checkpoint Ed25519 distinct du journal, lié au run ID, bucket, archive, digest, cycle et tête de chaîne. Publication après relecture et restauration distante. Vérification indépendante avec pin public et identifiant conservés séparément. Refus d'un checkpoint absent, modifié, rejoué ou d'un journal local tronqué. Aucun remplacement volontaire. Un écrivain unique est requis (B2 n'offre pas ici de création conditionnelle atomique). Le contrôle porte sur le checkpoint final, pas sur les étapes non encore ancrées. La vérification du checkpoint seul ne relit pas l'archive distante : publish effectue cette relecture. Le pin et le run ID doivent survivre hors VPS ; la rétention effective de chaque objet et la récupération après perte totale restent à qualifier. Tests sur stockage simulé, aucun timer ni autorisation métier.
