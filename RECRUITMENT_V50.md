# V50 — Qualification des candidatures REC

Le formulaire FR/EN existant accepte les candidatures spontanées. Les rôles RH et ADMIN disposent désormais du module Recrutement pour qualifier une candidature en profil consultant, une seule fois par demande. Les autres rôles ne peuvent accéder à cette nouvelle API. La demande originale reste intacte.

Recette : soumettre une candidature fictive, ouvrir `recruitment.html` avec un compte autorisé, saisir métier et compétences, vérifier le profil `A_QUALIFIER` dans le vivier. En tant qu'ADMIN, le coffre Documents existant permet de déposer un PDF fictif (catégorie CV, identifiant du consultant), chiffré et analysé par ClamAV. Aucun dépôt public de CV n'est autorisé dans cette version; ne pas utiliser de données personnelles réelles. Vérifier le refus des autres rôles et l'absence de doublons lors d'une nouvelle qualification.
