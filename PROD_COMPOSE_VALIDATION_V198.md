# V198 — Validation stricte du Compose PROD résolu

Contrôle hors ligne indépendant de la PR V197, construit à partir de sa topologie de revue. Aucun démarrage ni autorisation. Le validateur refuse les champs non prévus, les montages supplémentaires, les privilèges, le réseau externe, la dérive des ressources et la suppression du verrou. Les valeurs image et port attendues doivent venir d'une source indépendante approuvée. Le JSON résolu contient des secrets : ne jamais le publier ni le journaliser.

Commande de revue après fusion de V197 : docker compose --profile prod-review -f compose.prod.yaml config --format json | python3 prod_compose.py IMAGE_ATTENDUE PORT_ATTENDU. Utiliser uniquement une configuration privée ou fictive. Le contrôle strict peut refuser une représentation différente selon la version de Compose ; qualifier sur la version réelle avant tout usage. Les tests unitaires utilisent une représentation JSON synthétique, pas le moteur Docker. L'intégration CI sur le Compose réel sera faite après fusion de V197. V195 reste nécessaire pour contrôler la qualité et séparation des secrets. Le contrôle ne démontre ni la provenance de l'image, ni la disponibilité du port, ni la nouveauté du volume, ni l'état du socket ClamAV. PASS ne vaut jamais GO.
