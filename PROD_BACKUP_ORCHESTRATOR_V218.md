# V218 — Orchestration de revue sauvegarde PROD

Verrou flock exclusif dans un répertoire privé, appel du moteur V215, preuve JSON privée créée uniquement après validation distante et locale. Une preuve existante n'est jamais rafraîchie ; un objet disparu après preuve est refusé. Tests avec vrai schéma SQLite et adaptateur mémoire. Aucun timer ni CLI automatique. Le verrou ne protège que les opérateurs coopérant sur le même hôte et le même répertoire ; aucune garantie atomique inter-hôtes, ni preuve signée externe. Les chemins sont injectés pour qualification ; leur liaison aux chemins PROD fixes, la provenance des données et la fraîcheur doivent être contrôlées avant automatisation. Ne pas utiliser avec des données réelles. La preuve JSON n'est pas une autorisation de production. La V217 doit être testée sur le VPS avec B2 réel. Aucun changement REC, aucune purge.
